# Decisões do Projeto NÚCLEO

## Decisão 001 - Nome

O sistema se chamará NÚCLEO.

Motivo: representa a central da família, o ponto principal onde tudo se organiza.

## Decisão 002 - Uso

O sistema será usado igualmente em celular e computador.

Impacto: o frontend será responsivo desde o início e preparado como PWA.

## Decisão 003 - Stack inicial

Frontend: Next.js + TypeScript  
Backend: Java 17 + Spring Boot  
Banco de dados: PostgreSQL  
Infraestrutura local: Docker  
Estilo visual: dark navy, liquid glass, cards flutuantes, aparência premium
