# NÚCLEO

Central familiar privada para organização da família.

## Objetivo

Construir um SaaS familiar moderno para uso exclusivo da nossa família, com foco em:

- Finanças familiares
- Compras e mercado
- Agenda da família
- Tarefas e rotinas
- Organização da casa
- Membros da família
- Notificações
- Experiência web e mobile

## Identidade

Nome: NÚCLEO  
Conceito: Central da família  
Estilo: moderno, tecnológico, flutuante, liquid glass  
Cores principais: azul marinho, sapphire blue, icy blue e branco frio

## Estrutura

apps/web  - Frontend em Next.js
apps/api  - Backend em Spring Boot
infra     - Docker, banco de dados e infraestrutura local
docs      - Decisões, planejamento e roadmap
