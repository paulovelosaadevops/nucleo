# Núcleo — Central Familiar

Central privada para organizar a rotina familiar em um único lugar.

## Módulos

- Autenticação e segurança
- Núcleo familiar e membros
- Agenda
- Compras
- Finanças
- Notificações
- Configurações e auditoria

## Tecnologias

### Backend

- Java 17
- Spring Boot
- PostgreSQL
- Flyway
- JWT
- Maven

### Frontend

- Next.js
- React
- TypeScript

### Infraestrutura

- Docker
- Docker Compose
